# review

Pull request review workflows: address automated feedback, run iterative review-and-fix loops, and validate multiple PRs before merging.

## Install

```
/plugin install review@himattm
```

## Skills in this plugin

- `address-gemini-review` — triage and respond to gemini-code-assist bot comments on a PR.
- `review-cycle` — run an iterative review loop on a PR until it's clean.
- `validate-merge-prs` — batch-validate multiple open PRs (CI, reviews, code quality) and plan a safe merge order.
