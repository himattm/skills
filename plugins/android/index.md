# android

Android and Jetpack Compose development skills: scaffold a new project, fix edge-to-edge inset issues, drive the `android` CLI, and verify UI state on the emulator without burning main-context tokens on screenshots.

## Install

```
/plugin install android@himattm
```

## Skills in this plugin

The four skills below are listed in the sidebar — click through for the full workflow on each.

- `android-cli` — orchestrate Android dev tasks via the `android` CLI (project creation, deployment, SDK management, environment diagnostics).
- `edge-to-edge` — migrate a Compose app to adaptive edge-to-edge; troubleshoot inset-overlap and IME issues.
- `new-android-app` — scaffold a single-module Compose app with Metro DI, Circuit, Material You, Coil 3, kermit, Ktor, and Crashlytics.
- `verify-android-ui` — delegate screenshot and layout verification to a Sonnet sub-agent so the bytes never enter the main thread.
